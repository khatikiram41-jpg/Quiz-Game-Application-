🧠 Interactive Quiz Application

An advanced and interactive Quiz Application built using HTML, CSS, and JavaScript. This project provides an engaging quiz experience where users can answer different types of questions, track their progress, and receive their final score with detailed answer analysis.

The application supports multiple question formats, including single-choice questions, multiple-choice/multi-select questions, True/False questions, and fill-in-the-blank questions. Each question is displayed dynamically, allowing users to interact with the quiz without refreshing the page.

✨ Key Features

- 🎯 Multiple question types
- 🔘 Single-choice questions
- ☑️ Multiple-choice / multi-select questions
- ✅ True/False questions
- ✍️ Fill-in-the-blank questions
- ⏱️ Countdown timer for each question
- 📊 Dynamic progress bar
- 🧮 Automatic score calculation
- 🔄 Previous and Next question navigation
- 💾 Answer tracking and restoration
- 📋 Detailed answer review at the end
- 🏆 Performance-based result messages
- 🔁 Restart quiz functionality
- 📱 Fully responsive design
- 🎨 Modern blue-themed user interface
- ✨ Hover effects and smooth interactive elements

🛠️ Technologies Used

HTML5 – For creating the structure and layout of the quiz.

CSS3 – For creating the modern blue-themed interface, responsive design, gradients, animations, buttons, cards, and interactive effects.

JavaScript – For handling questions, user interactions, timers, answer validation, score calculation, navigation, and result generation.
